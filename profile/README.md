# Offline Works

A small studio making apps and games — the kind that load fast, respect your attention,
and keep working when the signal doesn’t.

Offline Works is an independent studio. Everything here is designed, written and shipped
by a very short list of people — which means fewer meetings, fewer features nobody asked
for, and a lot more care per pixel.

We build the software we want to use ourselves: things that open instantly, keep their
data on your device, and don’t need a server to be useful. Some of it is serious. Some
of it is a game. All of it is meant to outlast a trend cycle.
